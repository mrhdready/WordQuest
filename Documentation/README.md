# WordQuest — Dokumentation

Alle Projektdokumente liegen als Markdown in diesem Ordner. `.docx` wird nicht mehr gepflegt.

| Dokument | Zweck | Zielgruppe | Status |
|---|---|---|---|
| [`WordQuest_Konzept_und_Architektur.md`](WordQuest_Konzept_und_Architektur.md) | Fachkonzept und Architektur, jeweils mit Umsetzungsstand | Entwicklung | gültig |

Außerhalb dieses Ordners:

- [`../README.md`](../README.md): Überblick und Schnellstart
- [`../AGENTS.md`](../AGENTS.md): Arbeitsregeln für Coding-Agents
- [`../.planning/`](../.planning/): Anforderungen, Roadmap und aktueller Stand

## Regeln

- Eine Aussage über das System muss dem Code entsprechen. Ändert Code das Verhalten, wird das Dokument in derselben Änderung angepasst.
- Was geplant, aber nicht umgesetzt ist, wird ausdrücklich als solches markiert.
- Die Roadmap wird nur in `.planning/ROADMAP.md` gepflegt, nicht zusätzlich hier.
