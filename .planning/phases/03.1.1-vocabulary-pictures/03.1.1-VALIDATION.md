- **After every task commit:** der `<automated>`-Befehl des Tasks (gefilterter Backend-Lauf, vitest, betroffene e2e-Spec)

- **Before `/gsd-verify-work`:** 03.1.1-04 Task 3 (Gate und Release-Smoke aus dem Klon auf demselben Commit END)

**Rennen-Test:** Der gleichzeitige erste Upload (03.1.1-01 Task 2) ist nur mit erzwungenem Interleaving reproduzierbar (Zeilensperre auf `vocabulary_entry`, `WaitForBlockedAsync`). Bleibt er vor dem Fix grün, belegt er nichts; das SUMMARY nennt dann die Ursache.

**Filter-Falle:** `dotnet test --filter` ohne Treffer endet mit Exit 0; `backend-test.sh` bricht dann mit „KEIN TEST GEFUNDEN“ ab.

**Edge-Case-Matrix (AGENTS.md):** Das Bild-Formular hat ein Eingabefeld (Datei). Die Matrix rotiert über dessen Zustände, Happy Path zuletzt, exakte deutsche Texte (03.1.1-02 Task 1 und 2): Auswahl abgebrochen, PDF, kaputtes Bild, Server 400, 413, 404, 409, Netzfehler, doppelt ausgelöst, Entfernen, Ersetzen, Hinzufügen; Enter und Leertaste auf „Bild wählen“ als eigener Pfad.
