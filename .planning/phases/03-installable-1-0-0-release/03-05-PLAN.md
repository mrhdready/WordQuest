Was veröffentlichte Images braucht, kann vor dem Tag nicht stattfinden, weil erst das Tag die Veröffentlichung auslöst.
- **Was lokal nicht belegbar ist (D-12):** Veröffentlichte Manifeste, Pull aus GHCR (auch durch `upgrade.sh`, im Smoke nur per Spy), Betrieb auf einem Raspberry Pi 5 bzw. NAS, Lesbarkeit der root-eigenen Tagesdumps unter Linux (A9), `hostname -I` in der Abschlusszeile auf dem Pi, Traefik-Variante, eine Person ohne Projektkenntnis, Update auf eine spätere Version. - **Standardport:** Port 8080 ist auf dem Entwicklungsrechner belegt; der Smoke prüft 18082 über `WQ_PORT`. Die Seite behauptet nicht, dass der Standardport im Smoke geprüft wurde.
