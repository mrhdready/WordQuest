## Flagged Assumptions

- **Kein neuer Workflow (D-03, korrigiert):** `ci.yml:3-8` reagiert schon auf Tags `v*`, der Job `images` (`ci.yml:96-144`) baut beide Images für `linux/amd64,linux/arm64` und erzeugt über `type=semver,pattern={{version}}` aus `v1.0.0` den Tag `1.0.0` (dazu `latest` und `sha-…`, 03-RESEARCH Befund 1). Dieser Plan ändert `ci.yml` nicht. Veröffentlichen ist manuelle Abnahme durch Dennis (D-12).
- **Cross-Build reicht mit einer Zeile:** Die API wird framework-abhängig ohne RID veröffentlicht (`backend/Dockerfile:22-23`, `/p:UseAppHost=false`); 03-RESEARCH hat den Build mit `$BUILDPLATFORM` für beide Plattformen und den Start des amd64-Images geprobt. Für das Frontend ist die Ausgabe statisches `dist/` (A1, die Buildx-Probe in Task 3 deckt das auf).
- **Lokale Tags im Smoke:** Der Smoke baut die Images und benennt sie so, wie die Installation sie erwartet (`ghcr.io/mrhdready/wordquest-{api,web}:1.0.0`). Damit ist der Standard aus D-04 Teil des Belegs. Existiert eines dieser Tags vorher schon lokal (z. B. echtes Image nach der Veröffentlichung), bricht der Smoke vor jedem Build ab, statt es zu überdecken oder beim Aufräumen zu löschen.
- **Nicht exportiert:** `WQ_VERSION` und `WQ_IMAGE_PREFIX` werden im Release-Smoke nicht exportiert (Pitfall 3), anders als in `setup-smoke.sh:18-21`; sonst prüfte der Smoke die Werte aus `.env` gar nicht.
- **Port und Netz:** Smoke auf `18082` (8080 und 5432 sind belegt). `docker compose pull --ignore-buildable` in `setup.sh` zieht `postgres:17-alpine` und das Backup-Image; der Smoke braucht deshalb Netz wie der Phase-1-Smoke.
- **Traefik-Datei:** Der Hinweis aus 02-06 (Traefik-Stack braucht `frontend/nginx-traefik-realip.conf`) ist durch den Installationsweg `git clone` abgedeckt; die Seite verweist für die Traefik-Variante nur auf README Variante B (D-09).
- **URL-Provenance (AGENTS.md):** Jede URL, die auf die Seite kommt (Docker-Anleitung für Raspberry Pi OS, Repo-URL), wird in der Ausführungs-Session aufgelöst; nicht auflösbare URLs kommen nicht auf die Seite.
