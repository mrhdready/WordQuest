## Phase Goal

> A parent installs WordQuest in the home network over plain HTTP with their own account, generated secrets and daily backups, and can recover their own password and a child's forgotten PIN without help

Hinweis (MVP-Modus): Das Ziel ist nicht als User Story formuliert; eine Story-Fassung entsteht nur über `/gsd-mvp-phase 1`.

## Artifacts this phase produces

Dieser Plan liefert den Installationsweg der Phase:
- `AccountRules` (Identity-Modul), `AccountService` (Infrastructure), CLI-Verben `has-owner` / `create-owner` (`AccountCommands`, Verzweigung in `Program.cs`)
- Heimnetz-Compose `docker-compose.quick.yml` mit Secret-Dateien, Projektname `wordquest`, Demo-Seed aus
- `setup.sh` für den Heimnetz-Betrieb (fragt Image-Präfix, E-Mail, Passwort), `.env.example` mit `COMPOSE_FILE`
- neues Testprojekt `backend/tests/WordQuest.Api.Tests` (WebApplicationFactory gegen echtes PostgreSQL), CI mit Postgres-Service
- Smoke `.planning/phases/01-safe-home-network-install/smoke/setup-smoke.sh`, aktualisierte Doku (README, Konzept, AGENTS.md-Gate)
